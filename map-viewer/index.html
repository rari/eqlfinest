How the Map Viewer works

EverQuest Legends ships zone maps as text files: a base map plus optional label layers. This viewer loads those files in the browser so you can pan, search labels, edit points of interest by layer, and export either the map files or a rendered image.

Need the full zone map pack? Download rari-eqlmaps-20260804.zip (dark and light label sets), then drop zone .txt files here.

Got any powerful new spells to pick from? Set up your gems with our spell bars editor.

How to use

  1. Open or drop a base map <zone>.txt and optional label layers <zone>_1.txt to <zone>_3.txt.
  2. Search for a label, toggle layers, and edit text or positions as needed.
  3. Switch light/dark map background if the lines are hard to see.
  4. Download your edited files or export a PNG/JPEG render.
  5. Put them in your own folder under EverQuest Legends\maps, then switch to that map set in-game. You do not need to replace the default maps.

Create a personal map folder inside EverQuest Legends\maps and switch to it in-game without replacing the default maps.
