How the Loot Filter editor works

EverQuest Legends advanced loot uses per-character filter files with Loot, Merge, Store, and Sell lists. This tool helps you review those rules, combine filters, and export something you can use in-game without hand-editing a huge INI.

Off to somewhere new? Let our travel guide lead the way.

How to use

  1. Open a LF_<Character>_<server>.ini from your userdata folder.
  2. Browse and edit rules by category (Loot, Merge, Store, Sell).
  3. Merge filters when you want to combine your list with someone else’s.
  4. Download the zip, close the game if it is open, replace the file, then reload in-game.

Find loot filter files in C:\Users\Public\Daybreak Game Company\Installed Games\EverQuest Legends\userdata
