# Antonica’s Finest

Small browser tools for EverQuest Legends.

**Live site:** [https://rari.github.io/eqlfinest/](https://rari.github.io/eqlfinest/)

## Tools

| Tool | What it does |
|------|----------------|
| [Travel Guide](https://rari.github.io/eqlfinest/traveler/) | Find the shortest path across Norrath |
| [Map Viewer](https://rari.github.io/eqlfinest/map-viewer/) | View and edit zone maps offline |
| [Loot Filter](https://rari.github.io/eqlfinest/loot-filter/) | Clean up your advanced loot rules |
| [Spell Bars](https://rari.github.io/eqlfinest/spell-bars/) | Edit spell bars and see next upgrades |
